**A3 重跑判定（2026-08-11，配对 bootstrap）**：时间轴通道真正激活后仍是**零效应**——ΔF1 +0.003（CI [-0.005,+0.011] 跨零）、ΔRecall -0.0004、仅 2% 的题检索结果有变动。原因：LoCoMo 的时间题是"问时间"（When did X...）而非"含时间范围"（in May...），解析器无从出范围；偶发出范围时，并集捞的记忆与语义检索在此规模下高度重叠。（首轮 0.578/0.707 为空跑：当时 Retriever 未传 persistent_store，通道未激活，已修复。）**时间轴的真实试验场是 LifeBench/LME 时推子集/纵向数据集，不是 LoCoMo。**

**⚠️ 噪声地板（2026-08-08 配对分析定标）**：对同一批 1986 题做逐题差分 + 配对 bootstrap（2000 次重采样），**F1 侧全部配置的 95% CI 都跨零**（±0.01 是运行间 F1 噪声，来自答题 API 方差）；召回侧仅三个配置超出噪声带：**A1 -4.2（强显著）、A0 -2.4（强显著）、B2 +0.9（弱显著）**，其余差分 ≤0.3 且翻转率 ≤1.4%，为零效应。

**B 系列读数**：B1/B3 的零效应与 A2 一致，三个独立配置互证"L3/MMR 在 ~600 记忆/对话的规模下无从发挥"——不是机制无效，是规模没到拐点（设计场景为 10 万级）。B2 是 B 系列唯一真信号，方向符合设计（缺证据才补查），但它同时暴露下一层瓶颈：**召回再涨 F1 也不动，答题侧已是全系统瓶颈**。

**⚠️ 关键口径（必须随数字一起呈现）**：LoCoMo 导入是**数据集预结构化**的——observation 事实、session 摘要由数据集自带并在导入时直接使用（status="dreamed"），做梦的 Step1 结构化在此 benchmark 上从不执行。因此 A0 vs Full 隔离的只是**关联图谱（Step2）+ L3 融合（Step4）**的贡献（已验证 nodream 库 0 关联 0 L3）。做梦的核心价值（原始对话→结构化记忆）在 LoCoMo 上无法被测量——需在原始交互数据上另做实验（raw-turn 导入变体）。

**读数**：
- **在线图扩展（A1 vs Full）**：召回 +4.2、F1 持平，是图谱价值的**主要兑现通道**；ADV recall +7.8（0.619→0.697，扩展把反驳/佐证证据带出来）、MH recall +4.8（多跳证据互带，设计初衷）。F1 未随之上涨说明瓶颈已从"检索到"转移到"答得对"（prompt/答题侧）。
- **做梦静态产物（A0 vs A1）**：A1 召回反而低 1.7（0.668 vs 0.685）——图谱邻居不入池时，L3 簇占 top-10 槽位轻微稀释证据密度。即图谱离线建而不在线扩展，在 LoCoMo 上是负资产；价值必须经在线扩展兑现。
- 综合 A0/A1/Full：做梦产物（图谱+L3）的净效应全部经由在线图扩展释放（+4.2 召回），其中 Adversarial 是最大受益类。做梦的结构化价值以 Aditi 生产链路和后续 raw 导入实验呈现。

### 口径差异声明

1. **QA 集**：✅ 已核实无差异——LOCOMO 论文 v1（2024-03）的 7,512 题对应 50 个对话的初版发布；官方仓库 `locomo10.json` 是精选的 10 对话子集（1,986 题，见仓库 README Note 1）。本实验与 A-MEM、Mem0 论文均基于该文件，口径一致
2. **上下文预算**：A-MEM 每题 ~1137-2520 tokens；本实验 top-10 记忆摘要约 400-800 tokens——更少上下文
3. **3B 行模型**：本实验 3B 主结果为纯文本 Qwen2.5-3B（与 A-MEM 同款，决定性对比）；另有 Qwen2.5-VL-3B（多模态版）作为参考行
4. **prompt 差异**：本实验 QA prompt 显式要求 "Not mentioned in memories" 时拒答，直接推高 Adversarial——属合法设计差异但也含 prompt 工程成分

## 已知问题

1. **Temporal union 实际未触发**：query-time `now` 取真实 2026 年，LoCoMo 数据事件在 2023 年，相对时间解析出的范围匹配不到任何事件。要激活需按对话锚定 `now`（最后 session 日期）——留作下一步消融。
2. **Step5 分类器训练失败**：locomo 数据 label1 全是"对话"（单类别），分类器无法学习——不影响检索结果。
3. **conv-26 做梦来源**：使用早期 demo 跑的 settled 记忆（不是本次 LoCoMo eval 流程）。记忆结构与 locomo 导入一致，可对比。
4. **conv-30 / conv-50 修复**：conv-30 loader bug（list 型 dia_id）已修；conv-50 第一次跑时被 CLI resume 中断，第二次重导做梦完成。

## 下一步建议

- **Ablation 1 — 不做梦基线**：同 10 对话 `--dream-steps ""` 跑一遍，量化做梦贡献
- **Ablation 2 — 无图扩展**：去掉 `--graph-expand`，量化图扩展贡献
- **Ablation 3 — 时间轴激活**：query-time `now` 锚定到对话末 session，看 Temporal 类提升
- **答题模型矩阵**：补跑 `dashscope/qwen3-4b`（纯文本小 Qwen），与 A-MEM qwen-3b 行正面对标
